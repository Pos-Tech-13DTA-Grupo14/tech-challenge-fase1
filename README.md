## 🎯 Sobre o Projeto
Este repositório contém o desenvolvimento do Tech Challenge da Fase 1. O objetivo principal é construir um relatório executivo direcionado a investidores e acionistas do setor de e-commerce, baseado no *Brazilian E-Commerce Public Dataset by Olist*.

Nossa abordagem foca em transformar dados transacionais em narrativas claras sobre **Logística e Satisfação do Cliente**, culminando em recomendações acionáveis para o negócio.

## 🚀 Objetivos e Trilhas Analíticas
1. **Análise de Logística (SLA):** Mapeamento do Lead Time entre compra, aprovação, postagem e entrega.
2. **Impacto na Satisfação:** Avaliação da correlação estatística entre atrasos logísticos e o *review_score*.
3. **Desempenho Regional:** Visão geográfica através de mapas de calor das entregas.
4. **Text Mining (Sentimento):** Extração de temas recorrentes e análise de NLP nos comentários de detratores e promotores.
5. **Drivers de Satisfação:** Identificação dos principais ofensores e impulsionadores da nota do cliente (tempo, preço, categoria).

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Manipulação de Dados:** Pandas, NumPy
* **Visualização:** Matplotlib, Seaborn, Plotly
* **Processamento de Linguagem Natural (NLP):** NLTK, Regex
* **Ambiente:** Google Colab / Jupyter Notebook
